# Jogo de Adivinhação de Palavras

Projeto desenvolvido para a disciplina de Desenvolvimento de Aplicações Web I.

## Integrantes
- Escreva seu nome aqui

## Como jogar
Digite uma letra por vez e clique em **Tentar** (ou pressione Enter). O objetivo é descobrir a palavra secreta antes que as seis tentativas acabem.

Letras repetidas não descontam tentativas. Clique em **Nova partida** para sortear outra palavra.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Escolha aleatória entre dez palavras
- Palavra inicialmente escondida
- Controle de seis tentativas
- Identificação de letras corretas e incorretas
- Bloqueio de letras repetidas
- Mensagens de vitória e derrota
- Reinício da partida
- Envio da letra pela tecla Enter
